# WokMate
WokMate plans a classic Chinese breakfast and builds the shopping list.

## Model
We run Qwen/Qwen2.5-7B-Instruct, the 7B instruct model from the Qwen team on the Hugging Face Hub. It's small enough to run on a laptop, but per my notes it's only licensed for non-commercial use, so a paid hosted tier is off the table.

## Menu data
The starter menu is seeded from the breakfast (早餐) collection of the open-source HowToCook cookbook — about a dozen dishes to start.
